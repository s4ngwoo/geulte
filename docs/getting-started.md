# 시작하기

이 문서는 **컴퓨터를 거의 처음 만져 보는 분**도 따라 할 수 있게, 용어를 풀어서 적었습니다.
어려운 단어가 나오면 [용어 쉽게 풀기](glossary.md)나 [FAQ](faq.md)를 같이 보시면 됩니다.

## Geulte가 하는 일 (한 줄)

**Obsidian 같은 곳에서 쓴 마크다운 글 모음 → 예쁜 블로그 웹사이트 파일로 바꿔 줍니다.**

인터넷에 “항상 켜 둔 내 서버 컴퓨터”가 없어도 됩니다. 만들어 둔 HTML 파일들을 호스팅 서비스에 올려 두면 됩니다.

## 미리 준비할 것

1. **Node.js 20 이상**  
   - Node.js는 JavaScript를 컴퓨터에서 실행해 주는 프로그램입니다.  
   - [nodejs.org](https://nodejs.org)에서 LTS 버전을 설치하세요.  
   - 터미널에서 `node -v` 를 쳤을 때 `v20` 이상이면 됩니다.

2. **글을 쓸 에디터**  
   - [Obsidian](https://obsidian.md)을 추천하지만, VS Code나 메모장으로 `.md` 파일을 만들어도 됩니다.

3. (선택) **Git / GitHub**  
   - 글을 저장소에 올리고 자동으로 사이트를 갱신하려면 필요합니다.  
   - **필수는 아닙니다.** USB에 `dist` 폴더를 복사해 올리는 식으로도 가능합니다.

## 5분 체험

터미널(또는 macOS의 “터미널”, Windows의 PowerShell)을 열고:

```bash
# 1) 새 블로그 프로젝트 폴더 만들기
npx geulte init my-blog
cd my-blog

# 2) 필요한 라이브러리 설치
npm install

# 3) 미리보기 서버 켜기
npm run dev
```

브라우저에서 `http://localhost:3000` 을 엽니다.

- `npx` = “이 패키지를 잠깐 받아서 실행해 줘”라는 명령입니다.
- `npm install` = 프로젝트가 말하는 “의존 패키지”를 받아 오는 과정입니다.
- `npm run dev` = **내 컴퓨터에서만** 사이트를 미리 보여 주는 작은 서버를 켭니다.  
  인터넷 전 세계에 공개하는 서버가 **아닙니다.** 미리보기용입니다.

스캐폴드(자동으로 만들어 주는 뼈대)에는 예시 글과 `content/pages/about.md`(소개 페이지)가 들어 있습니다.

## 다음 단계

1. `content/posts/` 안에 `.md` 파일을 추가하거나 수정합니다. → [글 작성하기](writing.md)
2. 마음에 들면 빌드합니다.

```bash
npm run build
```

- 결과물은 보통 `dist/` 폴더입니다.  
- 이 폴더 안의 파일들을 정적 호스팅에 올리면 블로그가 공개됩니다. → [배포하기](deploy.md)

## 자주 막히는 곳

| 증상 | 힌트 |
| :--- | :--- |
| `node: command not found` | Node.js가 설치되지 않았거나, 터미널을 다시 열어 보세요. |
| `config.yaml을 찾을 수 없습니다` | `my-blog` 폴더 **안**에서 명령을 실행했는지 확인하세요. |
| 포트가 이미 사용 중 | `geulte dev -p 3001` 처럼 다른 포트를 쓰세요. |

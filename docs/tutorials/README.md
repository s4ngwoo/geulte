# Geulte 튜토리얼

아무것도 몰라도 **화면을 보면서 따라 할 수 있게** 적은 실습 모음입니다.  
개념만 빠르게 보고 싶다면 [FAQ](../faq.md) · [시작하기](../getting-started.md)를 먼저 보세요.

## 어떤 순서로 하면 되나요?

추천 순서는 **1 → 2 → 3** 입니다.

```text
① 로컬에서 사이트 띄워 보기
        ↓
② (선택) Supabase 연결 — 조회수·필터·sync
        ↓
③ Vercel에 올려 인터넷에 공개
```

| 순서 | 튜토리얼 | 결과 |
| :---: | :--- | :--- |
| 1 | [로컬에서 테스트하기](01-local-testing.md) | 내 컴퓨터 브라우저로 블로그 미리보기 |
| 2 | [Supabase 연동하기](02-supabase.md) | DB에 글 정보 동기화, 조회수·필터 준비 |
| 3 | [Vercel 연동·배포하기](03-vercel.md) | 전 세계가 볼 수 있는 주소로 공개 |

## 이 튜토리얼에서 쓰는 말 (초간단)

| 말 | 뜻 |
| :--- | :--- |
| **터미널** | 글자로 명령을 입력하는 창 (macOS: 터미널, Windows: PowerShell 또는 Windows Terminal) |
| **폴더 / 디렉터리** | 파일을 담는 상자. `cd my-blog`는 “my-blog 상자 안으로 들어가기” |
| **환경 변수** | 프로그램이 몰래 읽어 가는 설정값. 비밀번호·API 키를 코드에 직접 안 적을 때 씀 |
| **배포** | 만든 사이트를 인터넷에 올려 다른 사람이 접속하게 하는 것 |

## 시작 전에 공통으로 준비할 것

1. **Node.js 20 이상** — [nodejs.org](https://nodejs.org) LTS 설치 후, 터미널에서:

   ```bash
   node -v
   ```

   `v20` 또는 그 이상이면 OK.

2. **인터넷** — 패키지 설치·Supabase·Vercel 계정 생성에 필요합니다.

3. **(선택) GitHub 계정** — Vercel을 GitHub과 연결하거나 Actions로 자동 배포할 때 필요합니다.  
   로컬 테스트(1번)만 할 때는 없어도 됩니다.

## 얼마나 걸리나요?

| 튜토리얼 | 대략 |
| :--- | :--- |
| 로컬 테스트 | 10~20분 |
| Supabase | 20~40분 (계정·프로젝트 생성 포함) |
| Vercel | 20~40분 |

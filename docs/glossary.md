# 용어 쉽게 풀기

어려운 말을 **일상 비유**로만 풀어 둔 짧은 사전입니다.  
더 긴 설명은 [FAQ](faq.md)에 있습니다.

## SSG (Static Site Generation)

**미리 HTML을 만들어 두는 방식.**  
손님이 올 때마다 요리하지 않고, 도시락을 싸 두는 것에 가깝습니다. Geulte의 기본 모드입니다.

## 정적 호스팅 / CDN

완성된 파일(HTML, CSS, 이미지)만 저장해 두고 빠르게 나눠 주는 서비스.  
“내 프로그램이 24시간 계산”이 아니라 “파일 창고 + 배달”에 가깝습니다.

## 마크다운 (`.md`)

일반 텍스트에 `# 제목`, `**굵게**` 같은 가벼운 기호를 붙여 글을 쓰는 형식.  
Obsidian·GitHub이 잘 이해합니다.

## 프론트매터 (front matter)

마크다운 파일 **맨 위**의 `---` YAML 블록. 제목·날짜·태그 같은 **글의 신분증**입니다.

## 볼트 (vault)

Obsidian에서 말하는 **노트 폴더 전체**. Geulte에서는 보통 `content/`가 그 역할에 가깝습니다.

## 빌드 (build)

소스(마크다운·설정)를 읽어 **배포용 파일 묶음**으로 변환하는 한 번의 작업.  
명령: `geulte build`.

## `dist/`

빌드 결과물이 모이는 폴더(기본 이름). 이 안의 내용이 웹에 올라갑니다.

## 스캐폴드 / `geulte init`

새 프로젝트에 **기본 폴더·설정·예시 글**을 자동으로 만들어 주는 것.

## sync

빌드로 만든 글 정보 일부를 **Supabase DB에 맞춰 넣는** 과정.  
사이트 HTML을 대신 만들어 주지는 않습니다.

## Serverless 함수

서버 컴퓨터를 내가 켜 두지 않고, **요청이 올 때만** 짧은 코드가 실행되는 방식.  
Vercel의 `api/filter.js`가 이런 형태입니다.

## Supabase

Postgres DB + API를 클라우드로 빌려 쓰는 서비스.  
Geulte에서는 조회수·조합 필터·대시보드 등에 **선택적으로** 씁니다.

## Vercel

정적 사이트와 Serverless 함수를 배포하기 쉬운 호스팅.  
공식 스캐폴드의 **권장** 경로이지, 유일한 경로는 아닙니다.

## CI (예: GitHub Actions)

코드를 푸시하면 **로봇이 대신** `npm install` · `build` · 배포를 실행해 주는 자동화.

## WYSIWYG

“보는 그대로 편집” 화면 (노션·워드프레스 관리자 같은 것).  
Geulte 코어에는 **없습니다.** 에디터는 Obsidian 등을 씁니다.

## Taxonomy (택소노미)

글을 나누는 **분류 체계**. Geulte는 태그·토픽·키워드·카테고리·시리즈를 같이 씁니다.

## 하이브리드

본문은 정적 파일로 두고, 조회수·일부 필터처럼 **일부만** 실시간 API를 쓰는 섞은 방식.
